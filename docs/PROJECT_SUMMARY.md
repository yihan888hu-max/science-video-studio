# 项目总结：幸存者偏差科普动画

整理日期：2026-11-11。状态：首个30秒视频及运镜修订已交付；用户已授权上传本总结和审核包，目标为 yihan888hu-max/science-video-studio；远程结果以实际提交记录为准。

## 目标与最终范围
将经过核实的“幸存者偏差”知识，转化为普通观众只看短句与图像也能理解的动画。用户要求使用已有本地环境与HyperFrames，不调用付费服务，先审核内容再制作。
最初规格为1080×1920竖屏、30fps、30秒；之后改为1280×720横屏、30fps。当前有效交付为30秒连续运镜修订版，900帧，H.264视频和AAC双声道48kHz音频。90秒完整知识版仅有待选脚本，没有制作。

## 科学内容与取舍
知识稿完整说明：概念与选择偏差的关系；沃德的历史研究；战时装甲重量与防护分配问题；返航损伤数据的观测缺口；原始估计方法的用途；生活、基金业绩与经营场所队列中的当代意义。
核实后采用的表述是“沃德1943年的飞机脆弱性研究是经典案例”，没有证据认定他首次发现或命名这一术语。原始研究依赖数学模型与假设，不能简化为“弹孔少就一定要加固”。来源及论点映射保存在 knowledge/KNOWLEDGE.md。
30秒成片只展开一个教学假设：30天打卡计划中，只采访完成者，会漏掉未被采访者的经历。画面保留原始人群身份，通过观察范围和连线变化演示筛选；不展示真实完成率，也不把示意人数当作调查。
保留两条边界：停止打卡不等于停止跑步；缺失者不等于失败者。完整样本也不自动证明某种方法具有因果效果。

## 团队与审核链
agent1与agent2最终合并成知识稿组，共同检索、整理和复核人物归属、研究背景、原始用途与现代意义。agent1主笔，agent2共同研究并复核。
agent3接收用户审核后的知识稿，编写逐页演示/剪辑稿：每页写精确短句、构图、初始状态、动作、结束状态、观众可见结论、音效与阅读停留，关键逻辑不能由旁白兜底。
主agent核对事实和可视表达，制作静态样张、实现代码、渲染和检查。用户已通过知识稿、认可静态样张并授权首个30秒制作；随后提出动效和运镜升级。运镜修订已交付，但不能把新一次总结请求当成全部主观效果已获最终验收。
当前GitHub提交另设审核，不能沿用“同意制作视频”作为“同意上传”的授权。

## 视觉与镜头设计
参考用户提供的一条约199秒科普视频，抽取全片联系表及若干密集动作序列，分析近黑深蓝底、青蓝/暖珊瑚对照、局部柔光、线性图解与同场变化。未把参考片水印、原画面或其研究结论移用到原创片中。
静态方案通过后，所有解释图形均使用HTML/SVG绘制，没有寻找或生成外部照片。人物、文件、日历、节点和连线可编辑。
首版的问题是每页进入方式相近、运镜少，效果更像图解页切换。修订后使用一个持续存在的世界和独立相机：
1. 完成者近景和打卡日历，先给出日常问题。
2. 镜头真实拉远，原先在视野外的参与者自然进入。
3. 选择扫光触发采访流，镜头沿记录向右跟拍并推进局部。
4. 快速横摇回未被采访者，短暂水平模糊在落点恢复清晰。
5. 回到总体，样本范围框扩展，解释样本与总体的区别。
6. 记录框转成待补查问卷，路径扩展到未知者，保持问号。
7. 拉远收束，最后约3秒完全停稳。
文字留在屏幕坐标层，避免随相机缩小或在阅读时漂移。

## 技术实现与修复
HyperFrames 0.9.23负责挂载、预览和本地逐帧渲染；GSAP 3.15.0控制可定位时间轴；Python生成可编辑SVG/HTML及整理资料；FFmpeg/ffprobe负责音频后期、参数探测和解码抽帧。
关键修复：相机最初使用SVG包围盒相关的缩放原点，近景出现位置偏移和裁切，后改为固定SVG矩阵；调整了标签在运镜中的显隐，防止意外截断；旧版连线渐变挂载后不明显，改为清楚的半透明实色线；增大过小的教学标注。
Windows后台预览曾出现EXDEV注册错误，但状态与HTTP检查确认预览进程正常，渲染不受影响。保留工具版本，没有为了本片升级已有环境。

## 声音与素材
配乐最终使用用户提供的 We Never vibebgm.mp3，片内取原文件24.07–54.07秒；通过信号起音分析选段，没有宣称人工试听完成。
动作音效取本机media-use技能随附的whoosh-short与pop，随镜头和对象落点重新排布。最终混音实测约-15.06LUFS、真峰值-3.24dBTP。

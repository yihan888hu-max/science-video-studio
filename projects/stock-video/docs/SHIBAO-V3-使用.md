# 浙江世宝 · 立体蜡烛 K 线 V3

30 秒，1080×1920，30 fps。Composition：`ShibaoCandle30`。

## 本轮修改

主图使用真实 OHLC 蜡烛 K 线，正面渐变、暗色侧面、浅色顶面和亮边形成 2.5D 厚度；保留上影线与下影线。底部缩略图继续采用收盘线，帮助定位十年进度。

平稳时默认取约 43 个交易日的近期价格范围，缩放到约 600 px 的纵向高度，避免走势缩成细线。连续五个交易日涨跌幅从 12% 向 47% 增强时，取景范围从 43 天缩短到 22 天，进入急拉/急跌近景。蜡烛主体宽约 12—24 px。纵向按实际局部高低价自适应，保留读图安全边距。

镜头包含平滑横移、价格范围跟随、数据驱动的近景推进、轻微侧倾以及原有事件震动。活跃 K 线有额外取景约束，防止十年快速回放时跑出画面。文字和报价在固定屏幕层。

图表宽高轴会随取景范围变化，单根蜡烛的屏幕高度和画面斜率不能跨镜头直接比较收益；应阅读对应日期和价格。厚度、高光与阴影为视觉效果，原始 OHLC 数据保持原样。

## 使用

```sh
npm run preview:v3
npm run rebuild:v3
npm run render:v3
```

修改外观：`src/ShibaoCandle30.tsx`。
修改镜头规则：`scripts/build_shibao_v3.py`，然后运行 rebuild 和 render。
逐帧镜头：`src/shibao-v3-plan.json`。
输出：`out/zhejiang-shibao-candles-30s-v3.mp4`。

V3 沿用 V2 的历史日期推进、标注、原始行情与音轨，因此音效事件仍与同一行情帧对齐。V1/V2 保留。

# 浙江世宝 V5：连板、催化与停顿节奏

30 秒，1080×1920，30 fps。Composition：`ShibaoMarket30`。区间为 2021-01-04 至 2026-11-11。

## 本轮画面修改

主图继续使用透明立体蜡烛、真实 OHLC、发光边线与粒子。删除“近景”“快速下压”“极速拉升”等制作提示，删除近五个交易日涨幅和阶段百分比面板。改用“首板涨停”“N连板”“N天M板”“断板”“跌停”“长阴调整”等可与价格或收盘封板情况对应的文字。

参考视频为 `<本地参考素材目录>/mmexport1794410804844.mp4`，97.300 秒，1080×1920，60 fps。已检查每 5 秒联系表，以及 52—56 秒、每秒 5 张的连续抽样。参考表现为动作迅速落点、阶段停留、事件卡片保留、再继续推进；不能仅凭这些抽帧声称精确复制原片的缓动、停顿长度或音色。

普通关键蜡烛快速连续伸展 2 帧，然后完整保持 6 帧。重要节点另外延长停留：10连板、5连板完成后保持 26 帧，9天6板完成后保持 30 帧。镜头逐渐落稳，在较长停留后停止持续漂移。其他时期变速压缩；主图不是匀速时间轴，画面斜率不可直接跨段比较收益速度。

## 连板统计口径

图表沿用前复权日线；连板另用腾讯未复权日线核对。原始响应在 `reference-analysis/v5/tencent-unadjusted-2021.json` 至 `2026.json`，共与 1413 个项目交易日对齐。

对普通涨跌幅限制交易日，以前收盘价×1.10/0.90，按 0.01 元四舍五入比较收盘价。连续收盘封板累计“连板”；不连续时，以本轮起点至当前的交易日数量及封板数量列“几天几板”。本轮机械计数定义：相邻涨停之间超过三个交易日则开启新轮次。它不意味着所有市场资讯采用相同的统计窗口。除权除息、特殊交易规则日不能单靠前一日未复权收盘套公式；重点节点另外对照同期报道。

已独立对照的画面重点：

| 日期 | 标注 | 核验 |
| --- | --- | --- |
| 2022-06-24 | 10连板 | 未复权行情 + 财经网当日报道 |
| 2023-07-06 | 5连板 | 未复权行情 + 证券时报当日报道 |
| 2023-07-11 | 8天6板 | 未复权行情 + 财联社同期复盘（新浪转载） |
| 2025-12-26 | 9天6板 | 未复权行情 + 都市快报回顾 |

**2022-06-28 的特殊边界**：同期证券时报等报道普遍称“12天11板”；腾讯未复权收盘 15.56、日高 15.57，与按前收盘 14.15 四舍五入的参考涨停价 15.57 有一分钱收盘差异。本片以“同期报道口径”标记该文字，不自动把它计入严格收盘涨停，不把行情差异隐藏为精确机械计数。

规则依据：[深交所涨跌幅限制价格计算说明](https://investor.szse.cn/knowledge/stock/deal/t20180801_553961.html)。

## 催化与消息事实

画面区分“政策背景”“板块催化”“公司公告”。这些是已发生的信息与同期市场叙事，不能识别单一消息对个股涨幅的因果贡献，也不声称政策自动转化为公司的订单、收入或利润。

### 2022 年汽车消费政策背景

2022-05-31 财政部、税务总局发布公告：2022-06-01 至 12-31，符合价格、排量等条件的部分乘用车购置税减半。画面使用“部分乘用车购置税减半 / 汽车消费政策加码”，明确为政策背景，不断言它独自造成十连板。

来源：[浙江省税务局转载原公告](https://zhejiang.chinatax.gov.cn/art/2022/6/1/art_8409_82555.html)。

10连板报道：[财经网 2022-06-24](http://stock.caijing.com.cn/20220624/4870854.shtml)。
12天11板的报道口径：[证券时报报道的新浪转载](https://finance.sina.com.cn/stock/relnews/cn/2022-06-28/doc-imizirav1024357.shtml)。

### 2022 年停牌核查

公司在 2022-06-29 刊出的公告称，6月13日至28日累计四次异常波动、与基本面偏离较大，自6月29日起停牌核查。行情下一条记录为7月6日，收盘达到对应下限。因此该阶段显示“跌停”与“停牌核查后复牌”，不编造未公开利空。

来源：[公司《股票交易异常波动暨停牌核查公告》](https://epaper.stcn.com/con/202206/29/content_871932.html)。

### 2023 年智能驾驶政策预期

6月21日国新办政策吹风会上，工信部介绍启动准入和上路通行试点，并支持L3及以上自动驾驶功能的商业化应用。7月5日财联社记录智能驾驶板块开盘走强、浙江世宝4连板；7月6日升至5连板。画面称“智能驾驶政策预期升温”，不是虚构公司拿到订单。

来源：[财新记者对6月21日吹风会的原始报道](https://www.caixin.com/2023-06-21/102068028.html)、[财联社 7月5日](https://www.cls.cn/detail/1395434)、[证券时报 7月6日](https://www.stcn.com/article/detail/912525.html)、[8天6板同期复盘](https://finance.sina.com.cn/jjxw/2023-07-12/doc-imzaiunh9370945.shtml)。
公司同期异动公告还披露经营环境未发生重大变化、没有应披露未披露重大事项：[公告刊登页PDF](https://epaper.stcn.com/att/202307/07/1ff806e9-814a-4abb-9d56-a8df03a840b5.pdf)。

### 2025 年 L3 准入消息

12月15日首批L3级有条件自动驾驶车型获准入许可，限定在指定区域开展试点。随后市场关注智能驾驶相关产业链；浙江世宝12月16日至26日九个交易日有六次收盘涨停。画面列“首批L3车型获准入许可”，没有把其扩大成全国道路无条件可用，也不假称浙江世宝本身获整车准入。

来源：[工信部官网](https://www.miit.gov.cn/xwfb/mtbd/wzbd/art/2025/art_385be4a6a3da435cb94fdc83f23dff1c.html)、[都市快报 12月30日回顾](https://hzdaily.hangzhou.com.cn/dskb/2025/12/30/article_detail_2_20251230A131.html)。

## 工程使用

```sh
npm run preview:v5
npm run rebuild:v5
npm run render:v5
```

组件：`src/ShibaoMarket30.tsx`。
镜头/时序/声音生成器：`scripts/build_shibao_v5.py`。
市场标签：`src/shibao-v5-market.json`。
消息卡片：`src/shibao-v5-catalysts.json`。
输出：`out/zhejiang-shibao-market-30s-v5.mp4`。

生成器使用本地固定行情快照与原始未复权响应；更换或更新行情后，需重新核对除权特殊日、连板与来源。音轨按新落点重新合成。

## 已做检查与边界

TypeScript 与新组件 ESLint 通过；确认画面没有“近景”、近五日涨幅和制作提示词。
50 个关键蜡烛完成后的停留与下一根的先后顺序通过逐帧数据检查；四个独立重点连板节点通过对照；活跃蜡烛在正常回放的每帧均在安全取景范围内。
预览检查消息卡片和关键落点，成片解码抽帧检查。声音只做信号测量，未人工试听。

资料检索：Moli 做了两批共8个引擎检索，Brave提供了有效线索；其他路由出现空白、超时或验证码。随后用内置搜索补充官方政策、交易规则与公司公告。搜索摘要只用于定位，事实以页面正文、公开公告和行情对照为依据。

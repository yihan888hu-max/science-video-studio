# Agent 3：逐页演示与剪辑脚本规范

状态：脚本规范，非正式成片脚本。联合知识稿现已获得用户明确审核，用户已授权编写逐页脚本；仍不得据此制作画面、动画、音频或视频。当前正式待审稿见《逐页演示与剪辑稿-v3.md》。

## 工作交接与制作边界

1. Agent1 与 Agent2 组成知识稿组，负责资料核查、来源整理、生活案例、分析逻辑及事实边界。
2. 联合知识稿经用户明确审核后，交 Agent3 编写演示稿和剪辑稿。知识稿中的每一个被保留要点，必须对应到可见的解释证据。
3. Agent3 负责逐页屏幕短句、构图、演示动作及剪辑衔接。观众只看短句和图像也应能理解核心意思；旁白不能承担缺失的定义、条件或推理步骤。
4. 用户再次审核逐页演示稿与剪辑稿后，才进入媒体制作。知识稿通过不自动代表剪辑方案或媒体制作通过。
5. 用户当前未通过“跑步打卡群”主线，原候选稿仅作备选资料，不视为正式脚本。

## 已确定的参数与参考素材

- 成片：横屏 1280×720，30 fps。
- 时长：暂按 30 秒评估。先保证解释成立，不能为塞入 30 秒而省略必要推理；如超载，提交“删哪些内容”或“延长到多少秒”的明确选项，等待用户审核。
- 观众获取信息的方式：屏幕短句、图像和可读的动作结果。不能只画一个问号，再让旁白替画面解释。
- 用户指定的视觉方向：深色背景、局部柔光、发光节点、线性图标。发光仅引导注意或标示被观察状态，避免过度泛光遮挡文字，不将低亮/空心节点暗示为能力差、失败或不存在。

## 每页必须填写的字段

“页”是一个完整解释单位，可包含动作，不必等同于静止幻灯片。一页只承担一个主要解释任务；连续几页可使用同一组图形保持对象身份。

| 字段 | 必须回答的内容 | 审核准则 |
|---|---|---|
| 页码 / 对应要点 ID | 对应联合知识稿哪一个已审核要点？与前后页是什么因果关系？ | 每个核心要点有唯一 ID；重复出现时说明重复的目的。 |
| 解释目标 | 看完本页，观众应该能说出什么具体结论？ | 用一句可验证的话描述，不用“高级感”“震撼”等审美词替代目标。 |
| 屏幕短句 | 观众实际看见哪些字？每一句何时出现、消失？ | 主张句尽量控制在 8–14 个汉字；对象、条件需要补充时用贴近图形的短标签。不能为追求短而损害准确性。 |
| 构图 | 主体、辅助对象、标签、比较关系和安全区分别在哪里？ | 先指定视线顺序；主体足够大，文字不压在运动路径上。局部柔光服务信息层级。 |
| 动作起点 | 画面最初有哪些对象？各对象代表什么？哪些信息已知、哪些未知？ | 不用亮暗或颜色偷偷引入未经解释的编码；对象身份与上页连续。 |
| 动作过程 | 哪个对象如何移动、筛选、连线、变亮、分组或被遮挡？ | 一个主动作对应一个推理步骤；若有多个动作，明确顺序和各自用途。 |
| 动作结果 | 动作结束后，留下什么稳定画面？结果如何支持本页目标？ | 不听旁白也能看出关系变化；结果至少保留一个完整阅读窗口。 |
| 信息证据 | 哪个具体图形、位置关系、标签或变化证明本页主张？对应何种来源或示意假设？ | 列出“主张→可见证据→来源/假设”。不能只写“出现相关图标”。 |
| 转场 | 上一页什么对象被保留？本页如何产生下一页？ | 优先利用同一对象的变化交接；不得因切镜更换样本而制造不存在的比较。 |
| 效果音 | 哪个明确动作触发什么功能的音效？哪里需要安静？ | 音效用于标记进入、筛选、连结或结果落定；按动作设计，不逐字敲击；时间点仍为待制作计划。 |
| 停留 / 时间 | 页起止秒与帧、各动作时长、主文字落稳时刻、纯阅读停留长度。 | 30 fps，帧区间统一用左闭右开；主文案落稳后不漂移；最后一页留至少 2 秒阅读。 |
| 误解风险与修正 | 观众可能误把图形理解为什么？用什么可见标注或动作防止？ | 如“示意非实测”“空心代表未知”“未完成不等于退出”等，必须出现在需要它的位置。 |

## 要点到视觉证据的映射表

正式逐页稿开头先列以下表格，再写页面。由联合知识稿提供内容，本规范不替未审核知识稿确定要点。

| 要点 ID | 已审核的知识主张 | 普通观众需要的前提 | 必须看见的演示证据 | 所在页 | 证据性质 | 未覆盖部分 |
|---|---|---|---|---|---|---|
| K-待定 | 待用户通过联合知识稿后填写 | 待填 | 具体对象和关系，不能写“靠旁白解释” | 待填 | 原始数据 / 引用事实 / 教学假设 | 缺失则标明待解决 |

映射要求：

- 定义必须画出对象及关系，而不是只显示术语。
- 比较必须保持条件、样本身份、尺度和计量方式一致；条件不一致时必须可见地说明。
- 筛选必须展示筛选前总体、筛选规则、进入与未进入观察范围的对象；未被观察对象不能被删除成不存在。
- 推断必须显出“现有证据可说明什么”和“不能据此说明什么”；不把提出问题画成已经获得答案。
- 假设数字、人物分组和示意样本必须明确标识，不能伪装成调查结果；比例对推理非必要时不引入。
- 纠偏动作必须具体可见，如补查总体、标注未知、记录缺失原因；不能仅以“理性思考”作结。
- 文字说明仍无法被图形支持的要点，退回知识稿组检查表述或调整篇幅，不以增加旁白补洞。

## 时间与可读性核算

1. 先列完整的解释链，再逐页测算；不能先切六段，再硬塞事实。
2. 暂以一页一个主动作、一个主张句为起点。页数由解释需要决定，不固定六页。
3. 在 1280×720 画面中，主标题参考 48–58 px，说明标签参考 28–32 px；必要小注参考 22–24 px。优先减字与分步呈现，不靠缩小文字塞内容。
4. 左右边距至少 64 px，顶部至少 44 px，底部关键字幕至少留 54 px；实际平台遮挡需求若有新增再调整。
5. 每页区分动作时间与阅读时间：不能把文字在动画中移动的时间全部算作已读时间。主要信息出现后保持稳定画面。
6. 逐页稿完成后做一次静音通读：仅凭短句、图像、动作起点与结果，是否能重述完整推理？若不能，补画面或删内容。
7. 如果保留的知识点超过 30 秒承载能力，提交两种可审核方案：A 保持 30 秒，逐条列出移到配套知识稿的内容；B 保留全部必要步骤，列出新的总时长和每页时间。用户通过前不擅自延时或删去必要条件。

## 剪辑稿交付格式

正式交付包含：

1. 一个清楚的问题、一句观点、完整且有证据的解释链。
2. 要点→视觉证据映射表。
3. 逐页字段表，包括观众实际看到的全部短句和图像内容。
4. 连续镜头的对象交接说明，注明哪些元素保留、哪些变化。
5. 效果音意图与配乐段落意图，未选音乐段落时保持待定。
6. 信息覆盖、误读风险、时间核算和需要用户作出的明确审核选择。

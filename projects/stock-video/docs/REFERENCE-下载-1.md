# 参考学习与 V2 制作记录

日期：2026-11-11。参考文件：`<本地参考素材目录>/下载-1.mp4`。

## 实际观察

ffprobe：232.209 秒，2160×3840，60 fps，H.264/AAC。抽取了每 10 秒一个画面的联系表，以及 8、65、125、185 秒的独立较大画面。

观察到的表达方法：

1. 竖屏深色舞台，上部固定显示指数、报价和日期，中央放阶段事件，主图连续移动。
2. 日线/价格线呈红绿霓虹色，白色细芯、宽柔光、端点亮光与粒子增强运动方向。
3. 图表与镜头一起推进；急跌和急涨具有更大的视觉重音，过去走势仍保留空间关系。
4. 阶段文字、百分比、参考日期与事件在走势中出现；结尾拉回更大尺度。
5. 部分阶段加入市值排名、公司标识和矩形分布图，信息密度明显高于我们的 30 秒短片。

抽样不能准确反推全片镜头、软件、缓动参数或音乐节拍。本轮没有人工试听参考片，不声称复制其音色或声画卡点。联系表不是完整分镜表；相邻抽样间隔不代表镜头长度。

## 实施到本项目

新增 composition：`ShibaoReference30`，30 秒，1080×1920，30 fps。

- 从旧版四段独立图表，升级为 2016-11-08 至 2026-11-06 的连续十年走势。
- 同一数据空间内跟随曲线端点；价格 HUD、日期、文字保持屏幕坐标。
- 主线是逐日收盘价，近端辅助显示真实 OHLC 日 K；红涨绿跌，叠加白芯、柔光、端点粒子和纵向拖尾。
- 当下五个交易日涨跌幅绝对值超过 12% 后开始增强镜头，达到 52% 时达到最大推进；平滑处理镜头目标，普通变化不持续震动。
- 五个交易日涨幅 ≥25% 或跌幅 ≤−20% 的历史事件，相邻五个交易日内的同向信号合并，取组内最强点作为回看重音。当前有 17 个事件，七个文字标注。
- 历史事件脉冲驱动短震动、环形冲击、预备气流声及低频冲击声。音效与相机共享同一数据计划中的帧号。
- 底部保留全十年缩略图与当前位置，帮助观众理解当前观察窗口。
- 末段平滑拉远到全景，显示区间首末收盘变化 −31.6%（19.824 → 13.560）。数值使用原始精度计算，显示价格取两位小数。

镜头之外，历史日期推进采用变速压缩：重要波动期较慢，平缓段较快。**视频横向空间与时间均被压缩，局部与全景的缩放不同，不能用画面斜率直接比较收益速度。** 事件是事后回看选择，不是可交易的预测信号。

没有迁移参考片的公司排名、事件归因、水印、图标、声音和原画面。浙江世宝的阶段文字只描述本项目已保存行情数据能够支持的涨跌事实。

## 声音

`scripts/build_shibao_v2.py` 用确定性的正弦波、噪声与包络合成电子氛围、低频节拍和冲击音；本片没有人声。音频生成代码留在项目，可重复生成与改节奏。未复用参考片声轨。

AAC 成片测量：综合响度约 −18.48 LUFS，真峰值 −1.60 dBTP，无削波。完成信号测量，未人工试听，不将测量结果当作主观听感验收。

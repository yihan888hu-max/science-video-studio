# agent2：生活案例与解释逻辑（审核稿）

状态：仅策划，未制作视频、图像或音频。规格：1280×720、30 fps；按原计划暂以 30 秒评估信息量。以下案例用于解释逻辑，不声称已取得行业统计数据。

## 推荐案例：为什么觉得旧家电特别耐用？

开场问题：“老风扇还在转，所以以前的家电都更耐用？”

明确观点：“仍在使用的老家电，已经经过时间筛选；只看它们，不能判断当年所有家电的质量。”

选择理由：家中旧电风扇有具体物体与动作，观众容易理解“坏了被丢弃，所以今天看不到”；可以从一台风扇拉远到同批产品，再显现已淘汰的产品，视觉变化直接对应证据变化。没有金融知识门槛，也不需要假定推荐算法行为。

| 分析项 | 内容 |
|---|---|
| 最初总体 | 某一时期购入、可比较的一批家电；如比较新旧质量，还必须定义相同品类、使用强度等条件 |
| 筛选过程 | 经长期使用，坏掉或被替换的产品退出家庭；仍能用的产品被保留到今天 |
| 看得见 | 家里仍在使用的旧风扇 |
| 缺失样本 | 同期已经损坏、淘汰或被替换的家电及其寿命记录 |
| 错误推断 | 从“这台旧风扇很耐用”推到“以前生产的家电普遍更耐用” |
| 如何纠偏 | 比较同类产品完整的寿命或故障记录，并考虑维修、使用环境、负荷和淘汰原因 |
| 推断边界 | 可能确有代际质量差异；这个例子说明单靠眼前幸存品无法判断，不能据此反过来断言老家电没有更耐用 |

演示可只画一组产品，无需给出数量。若确需数量，可用“假设当年有 10 台，如今留下 2 台”，并持续标注“虚构示意，非真实故障率”；这些数字不能进入研究结论。

## 备选一：跟着上岸经验，就一定能考上？

| 分析项 | 内容 |
|---|---|
| 最初总体 | 在相近考试条件下使用某学习方法的考生，及适当的对照人群 |
| 筛选过程 | 只采访或查看已经考上的人 |
| 看得见 | 成功者分享的学习安排 |
| 缺失样本 | 采用相同安排却未考上的人；也包括采用其他方法的考生 |
| 错误推断 | “这些人都这么做，所以这么做就能考上” |
| 如何纠偏 | 看使用该方法的总人数与不同结果，区分基础、投入时间、资源差异；判断方法效果还需要更好的比较 |
| 推断边界 | 成功经验可以提出假设，不能单独证明方法有效或无效；并非所有经验贴都存在同样的筛选 |

开场：“同样的备考方法，没考上的人去哪了？”

注意：不要把所有考试表现归于运气；也不要编造平台只推送上岸者的事实。

## 备选二：街上只剩老店，所以开店很稳？

| 分析项 | 内容 |
|---|---|
| 最初总体 | 某地区某段时间实际开过的同类店铺 |
| 筛选过程 | 只走访今天仍在营业的店铺 |
| 看得见 | 留到今天的店铺和经营者故事 |
| 缺失样本 | 同期已关门、迁址或转行的店铺 |
| 错误推断 | 从仍在营业的店推断“多数开店的人都能长期经营” |
| 如何纠偏 | 找到开业与退出的完整记录，分清关闭、迁址和转型，使用清楚的分母 |
| 推断边界 | 关门未必是亏损，继续营业也未必代表盈利；“存续”“盈利”“成功”不能混为一谈 |

开场：“这条街上都是老店，开店真的这么容易？”

## 备选四：只问还在跑步的人，能说明所有人都适合？

| 分析项 | 内容 |
|---|---|
| 最初总体 | 同一跑步计划最初的全部参与者 |
| 筛选过程 | 结项后只调查仍坚持参加的人 |
| 看得见 | 坚持者的感受和记录 |
| 缺失样本 | 中途退出者及其退出原因 |
| 错误推断 | 从坚持者的正面体验推断“最初每个人都获得同样收益” |
| 如何纠偏 | 联系退出者，记录不同结果与退出原因，并承认失访限制 |
| 推断边界 | 退出可能来自时间安排等原因，不能自动当作受伤或无效；本例不提出健康建议 |

开场：“只问坚持下来的人，会漏掉什么？”

## 推荐案例的 30 秒解释骨架

这是内容节奏提案，最终剪辑文字由 agent3 统一。

- 0–4 秒：一台旧风扇在转。提出“旧家电都更耐用？”
- 4–10 秒：镜头拉远，显示同批家电。提醒“你看到的是留下来的”。
- 10–17 秒：坏掉或淘汰的家电退出画面，随后用虚线显现“被丢弃的同期产品”。动作必须让观众知道缺失样本来自原来的同一批，而不是凭空出现。
- 17–24 秒：并列呈现“仍在用”和“已淘汰”，补齐观察范围。命名“幸存者偏差”。
- 24–30 秒：回到风扇，给出可行动的结论：“判断整体，先找没留下来的样本。”

## 论证链与审核要点

问题（旧物都更耐用？）→ 观察（眼前旧风扇仍在转）→ 检查样本（它经过长期留存筛选）→ 补看遗漏（同期淘汰品）→ 修正推断（不能由幸存品代表同期全部）→ 纠偏行动（找完整记录、比较条件）。

这条链只证明现有证据不足以支持“以前普遍更好”，不证明相反结论。避免“幸存者都只是幸运”“成功者经验没用”“缺失样本一定都失败”等说法。

若必须在同一视频讲清沃德、1943 年历史和生活案例，30 秒很难同时讲透；建议历史放知识稿或另做一集，短片集中解释一个例子。若审核决定保留飞机主线，旧家电只作为结尾一句生活迁移，不再额外展开考试、开店等案例。

## 合稿优先方案更新：30 天跑步打卡群

与主稿、agent3 协调后，本轮 30 秒短片优先使用跑步打卡群。前文旧家电保留为备用独立方向。

开场问题：“群里剩下的人都在打卡，就说明这个计划很容易坚持？”

核心观点：“只看坚持到最后的人，可能高估这项计划对最初所有参与者的可坚持程度。”

- 最初总体：同一次计划最初的全部报名者。
- 筛选：经过 30 天，部分人继续打卡，部分人因各种原因停止。这里是叙事设定，不是假定真实社群统计。
- 可见样本：在终点仍打卡、仍参与分享的人。
- 缺失样本：中途停止的人及其经历。
- 错误推断：凭终点可见者的表现推断所有最初参与者都容易坚持。
- 纠偏：找回最初名单、联系退出者、检查停止原因。若要算完成比例，需完整且定义一致的分母与结局记录。
- 边界：停止打卡未必停止跑步；退出可能来自搬家、忙碌、隐私或记录习惯，不应等同于懒惰、受伤、无收益。

适合剪辑稿的一句话：“你看到的，是留下来的人；中途离开的人，也属于原来的样本。”

视觉建议：同一张报名名单在镜头里连续存在，完成者高亮、停止者变暗而不是被抹掉；再让画面裁成仅含完成者的小窗，直接展示观察范围如何缩小。结尾拉回完整名单，缺失样本回到视野。数量只表达示意，不给出貌似实测的坚持率。

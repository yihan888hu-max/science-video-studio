# 浙江世宝 · 参考风格 V2

V2 主工程：`src/ShibaoReference30.tsx`。数据与镜头生成器：`scripts/build_shibao_v2.py`。逐帧计划：`src/shibao-v2-plan.json`。分析记录见 `REFERENCE-下载-1.md`。

## 直接使用

在 `vibe-video` 项目目录运行：

```sh
npm run preview:v2
npm run render:v2
```

预览地址以 Studio 打印的端口为准，选择 `ShibaoReference30`。输出为 `out/zhejiang-shibao-reference-30s-v2.mp4`。

修改图形、文字、字体、粒子数量：编辑 TSX，Studio 自动刷新；修改行情、事件阈值、日期推进或合成声音：编辑生成器，运行：

```sh
npm run rebuild:v2
npm run render:v2
```

只改 TSX 无需重新生成音轨。数据计划、声音来自同一脚本；修改事件后应同时重建两者。

## 后续导演方法

先说明一条视频的问题、时长、画幅与参照，再把分析结论映射为可见证据。优先连续保留同一对象，镜头因当前信息变化而移动；价格与标题层分离，动效不改写数据。

当前风格规范：近黑深蓝背景，涨红跌绿，关键回看结论用暖金；固定报价和日期，主图跟随端点，重要事件放慢，落点留阅读时间。参考中的复杂排名或真实事件仅在有可靠资料时加入。

每次修改使用新输出版本名。交付 MP4 时一起保留源代码、数据快照、音乐/音效来源和 QA 记录；不从旧 MP4 重新反推工程。

新音乐到达后先分析节拍并试听选段，再在数据事件附近调整日期推进；重要的价格事件保持原交易日顺序。不能为了匹配鼓点改变行情数值或捏造新闻原因。

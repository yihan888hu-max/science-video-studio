# 短线术语：定义、证据与使用边界

同一术语在淘股吧、媒体和交易者之间可能有不同口径。这里是研究和标注的证据门槛，不是交易策略。每只股票另外填写日期、事实、计算口径、来源、是否可入片。

| 术语 | 可观察含义与最低证据 | 表达边界 |
| --- | --- | --- |
| 首板/连板/几天几板 | 未复权收盘达到该日适用涨停价；连续交易日计连板；断续轮次注明起止和交易日口径 | 除权参考价、ST状态、上市特殊日需单独核验；日高触板不自动算收盘涨停 |
| 一字板 | 开高低收均为涨停价；有成交的实际日线 | 不由一字形状推断买不到、封单金额或资金身份 |
| T字板/T字回封 | 开盘与收盘均涨停、盘中最低价低于涨停；可证明开盘触板、回落后收在涨停 | 精确封板/炸板次数、最后封板时间需要分时/盘口或可靠涨停数据 |
| 回封 | 触板/封板后打开，再返回并封住 | 一般情形需要分时与封板记录；日线O低于涨停、H=C涨停不能证明中途打开过 |
| 炸板回落 | 盘中达到涨停价，收盘低于涨停价，能由可靠OHLC识别收盘未封住 | 不从日线编开板次数或盘中路径；“炸板”也可能被复盘口语用于曾打开又回封，须说明 |
| 反包/涨停反包 | 定义使用收盘、实体还是最高价包住前阴线，列出比较值；涨停另核对上限 | 不把所有阴后阳都称反包 |
| 地天板/天地板 | 同日触及跌停与涨停，先后顺序另需分时证明；收盘端需对应 | OHLC同时含两极不够证明顺序 |
| 缩量/放量 | 成交量/额相对前日或明确N日均值的倍数 | 写明参照，低成交量不等于卖压消失 |
| 缩量加速 | 缩量事实+连续封板/价格推进更快的事实；“加速”是事后描述 | 不推断筹码完全锁定、次日必涨 |
| 换手/高位换手/爆量换手 | 可靠成交量与当时流通股本/换手率；明确“高位”相对哪个区间 | 只有成交量时改称“高位放量”，不伪造换手率 |
| 分歧/一致/弱转强/强转弱 | 盘中回撤、封板状态、成交放大、相对强弱等证据；注明作为复盘解释 | 不能仅用颜色代替事实或假称所有资金同一观点 |
| 龙头/容量核心/情绪核心/补涨/卡位/穿越 | 同期板块相对涨幅、连板高度、成交额与可信复盘出处 | 是相对定位，不是官方身份；避免以事后成功作当时必然 |
| 首阴/断板/龙回头/二波 | 先定义所指连续上涨/板序列及调整区间，日线验证 | 区别首根阴线、首个下跌日和首次未涨停；二波不代表必有下一波 |
| 情绪退潮/负反馈/亏钱效应 | 板块涨停数量、炸板率、高标跌停/回撤、成交变化及同期复盘 | 单股回撤不足证明全市场退潮；单股可称“高位回撤” |
| 无量跌停/流动性枯竭 | 无量跌停需低成交对照+收盘跌停；流动性枯竭还需买盘/深度、封单、连续成交受阻等证据 | 价格大跌或成交量减少本身不证明流动性枯竭 |
| 异常/严重异常波动 | 当时有效的交易所规则、适用基准、计算窗口/重置与上市公司公告 | 偏离值≠股票简单涨幅；不能跨年度套同一规则或当作自动停牌承诺 |
| 卡异动/控异动 | 交易者对阈值附近走势的解读；需原帖日期、实际规则和行情对照 | 标“市场复盘观点”；公开数据不证明合谋控盘、资金主观意图或监管结果 |
| 游资/主力/席位/量化 | 龙虎榜或公开席位数据，区分营业部席位与特定自然人 | 不把营业部直接等同某个人，不从K线猜资金身份 |

监管资料优先交易所当时规则和公司公告。例：[深交所2023年严重异常波动投教说明](https://investor.szse.cn/knowledge/t20230406_599705.html)用于理解历史口径；实际项目仍核对事件日适用规则、重置条件和公告，不能把旧说明当作未来恒定规则。

论坛是市场语言与同期情绪的来源。记录原帖与发布时间，和公司公告、交易数据分别存档；不能把帖子中未经核验的封单数字、内幕、席位身份、涨价原因或预测复述为确定事实。入片状态可为“可计算事实”“公告事实”“注明出处的市场观点”“证据不足暂不入片”。

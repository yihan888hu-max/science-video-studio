# 原制作环境

Windows 11；i5-10200H、约16GB内存、GTX1650Ti约4GB显存。
制作时使用 Node 26.13.0、Python 3.10.7、FFmpeg/ffprobe 9.0.1、Chrome、HyperFrames CLI 0.9.23、GSAP 3.15.0。
工作区另有 Remotion 4.0.541 基础示例和 Hypit CLI 0.3.1；本片由HyperFrames完成。Hypit运行时、生成和转写未充分验证，不作为可用能力承诺。

原工作区有HyperFrames、HyperFrames CLI、media-use、ffmpeg-skill与science-video技能。仓库保留精简science-video流程，使用者应使用自己安装的官方工具。
HyperFrames Windows后台预览曾报EXDEV注册错误，但进程状态和HTTP200核查通过；不要将本机localhost链接当成长期共享地址。
源工程固定0.9.23以便复现；本记录不代表目前最新版本，也不在提交准备阶段升级环境。

# 可换股票的日K视频工作流

确认范围与数据截止日 → 研究资料摘要 → 核验术语及消息时间 → 生成日K/相机/停顿/音效时间轴 → Studio预览 → 渲染并质检 → 保留版本。

## 这套系列必须保留的修改

1. **形态**：真实OHLC蜡烛，影线、玻璃透明正面、立体侧面与顶面、明亮边线；主图不是收盘折线。底部缩略线定位历史。
2. **运镜**：镜头跟实际波动。平稳期也按近期价格范围适当放大；急涨急跌推近、跟随、短震动。标注固定在屏幕上，不能随相机乱晃。
3. **停顿**：关键K线快速连续长完，然后停留完整形态，再进入下一根。不是将一根K的生长过程拖慢或暂停。里程碑停更久，镜头落稳。
4. **色彩**：深邃背景，红涨绿跌；主升振幅扩大增加红色氛围，大跌增加绿色氛围，文字保持清晰。
5. **声音**：电子感、辨识度、短瞬态与紧低频分层；落在蜡烛完成点，背景让位。提供音乐时先分析节拍和试听，再调行情播放节奏，不改交易日顺序。
6. **文案**：去掉“近景”“快速下压”等制作词，不放“近5交易日+25%”重复面板；用经核验的连板/几天几板、断板、T字回封、炸板、缩量等表达。
7. **消息与情绪**：每股先做研究摘要，分行情事实、公告事实、市场观点。使用公开日期。产业政策≠公司业绩。论坛“卡异动”“抱团”等须标市场解读；缺盘口就不写流动性枯竭、炸板次数等断言。
8. **顶部**：事先定义波段起点，显示低高价、低高振幅、交易日含首尾、自然日和日期。年度高点与跨年延伸顶部区别展示。
9. **工程**：旧版本保留；新股票使用同一渲染器和生成脚本，只新增项目配置、行情、摘要和消息证据。详见项目brief.json。源码、音轨、数据、时间轴、核验结果均可复用。

## 换股的方法

- 新建 `projects/<股票>-<范围>/`，先写 `research/summary.md`（必需），保存原始行情和资料链接。参考航天发展目录结构。
- 可先用现成行情下载器（复用缓存，不安装依赖）：`python3 scripts/stock_video/fetch.py --symbol sz000547 --from 2025-01-01 --to 2026-11-11 --project projects/aerospace-2025`。换股修改symbol、目录和起止日期；检查实际返回截止日和公司身份，不能默认请求日期都有行情。
- 准备`daily.json`：`[日期,开盘,收盘,最高,最低,成交量]`，按日期升序；`unadjusted.json`保存未复权和区间前一交易日，遇除权须提供交易所前收/参考价。默认生成器拒绝缺失前收和未复权对应日。
- 复制brief配置，改name/code/id、截止日、实际涨跌停制度、重点范围、消息/出处/首次公开日期、峰值定义、帧时长。上市无涨跌幅、ST变化、除权等特殊日期用`limits`显式提供当日价限；不要只改代码。
- `python3 scripts/stock_video/build.py projects/<目录>/brief.json` 生成`src/stock-videos/<id>.json`、原创音轨、timeline.csv和validation.json。它检查摘要存在、关键术语有证据、消息不早于公开日、峰值统计以及相机安全取景。
- 在`Root.tsx`新增一个独立Composition，导入对应JSON，复用`StockMotionVideo`（与Aerospace2025注册相同）。Studio会热更新；编译和预览后渲染。
- 示例：`npm run rebuild:aerospace`、`npm run render:aerospace`，预览`http://localhost:3000/Aerospace2025`。

普通行情被时间压缩，关键K线保留独立生长/停留。量能与价限使用未复权资料，统计涨幅使用统一复权口径。完整Skill位于仓库根目录的`.agents/skills/stock-video/`，以后可直接说“使用 $stock-video 做某股某段行情”。若当前会话技能列表未热刷新，新聊天可识别；也可直接读取该SKILL.md。

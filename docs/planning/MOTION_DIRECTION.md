# 幸存者偏差30秒片：动效与运镜修订方案

职责范围：导演与脚本文字规划；未修改动画代码、音轨或视频。供主 agent 在现有工程 ${WORKSPACE}/outputs/survivorship-bias-30s-v2 中实施。

## 改动目标

维持已获认可的静态视觉、原有核心文案、30秒总长、1280×720、30fps及不使用付费服务。把“六段依次出现”改成“一个连续空间被镜头逐步揭示”。用户要增强的是场景连接、镜头运动与动作设计，不能只加快出现速度或增加泛光。

参考依据为已实看参考片后形成的《参考视频风格分析.md》：手机搜索框推近、脚印沿路前进、同一坐标补充第二种情况、画面从局部拉远至总体。这里借用其“镜头跟着解释走”的方法，不声称原片有本文拟定的具体速度曲线、音效或所有转场。

## 最有价值的三项调整

1. 4秒处的拉远必须真正揭示原本在视野外的同一批报名者。先让观众体验“只看完成者”，再亲眼看到视野扩大后的遗漏。用构图变化完成科学解释，无须先换一张新图。
2. 9–15秒的镜头跟随采访记录向窗口移动，再摇回仍未被采访的空心节点。完成者窗口和原总体保持空间关联；镜头有明确追踪对象，观众知道为什么向这里看。
3. 文案固定在屏幕坐标，图形在世界坐标中运动。每次主运镜后停1.5–3秒，主图动作有重音、文字有阅读段，避免整段相机漂移导致字幕和标签都读不清。

## 连续空间与对象身份

建议SVG内设置一个可寻址的世界组，包含原报名队列、日历、观察窗口、采访线路和调查标记。只由一个相机组控制世界组的缩放和平移；主文案、教学示意与关键提示保持屏幕层固定。具体SVG和GSAP组织交主 agent 实现，本文不新增代码。

- 左侧：原报名队列与未被观察的空心节点。
- 中央：日历与已完成打卡的节点，是开场镜头所在位置。
- 右侧：采访窗口与已被展示的记录。
- 同一人物在全片保持身份与位置，允许其记录作为独立线性纸页沿采访线移动；不能把人本体复制到两处却不说明。
- 青蓝发光编码被观察的记录，空心/低亮编码尚未观察；暖珊瑚仅用于范围缺口、问题或调查焦点。不能把空心节点淡出为不存在，也不能在补问时擅自补成失败。
- 观看路径依次为：完成者局部→原始总体→采访记录流→遗漏节点→补查路径→总体与结论。

## 30秒镜头设计

时间均为拟定剪辑时刻，帧区间左闭右开。相机尺度以“完整总体可读的基准构图”为1；数值是适配起点，主 agent 需以1280×720实际画面核查字形和遮挡。镜头运动只发生在中央图形层。

| 时间 / 帧 | 镜头与主动作 | 对象交接、画面初末状态 | 镜头为什么发生 / 信息结果 | 重音与阅读停留 |
|---|---|---|---|---|
| 0–4秒 / 0–120 | 从完成者与日历最后一天的近景开场；0.25–1.0秒小幅推近，约1.42→1.55，随后停。 | 首帧已有可辨的人物、日历与“完成者分享”窗口；记录通过一条短线进入窗口。日历最后一天的方框与采访窗口共享同样圆角和描边，为后续展开准备形状。 | 不是空背景先上标题；观众第一眼就看到“被展示的意见来自完成者”。镜头推近只强调当前局部，不暗示已经看到总体。 | 约0.85秒记录入窗为第一动作重音；1.2–3.7秒保持问题可读。主问题不跟镜头放大。 |
| 4–9秒 / 120–270 | 4.0–5.25秒主拉远，约1.55→1.0，平移到完整报名队列中心；5.3–5.8秒轻量边界展开。 | 开场日历最后一天的方框向外展开为观察窗口边界；完成者始终留在相同世界位置。视野外的空心节点随着镜头拉远自然进入画面，而非一个个凭空淡入。总体边界由原名单线索连续画出。 | 镜头扩大视野等于扩大观察范围，揭示“最初还有这些人”。对象身份与开场相连，观众不会把它误当另一批报名者。 | 拉远落点约5.25秒；边界闭合约5.7秒。6–9秒保持完整队列与标签，供对照。 |

| 15–20秒 / 450–600 | 15.0–16.1秒回到能同时看到样本窗和总体的宽构图；16.2–17.4秒由窗口尝试向总体投射范围，随后停止。 | 窗口矩形在相同坐标向总体伸展，遇到空心节点时露出缺口，不能完整覆盖。用缺口/未连接线表达“样本不是全部”，概念标题在固定文字层落定。 | 概念不靠标题轮换：观众实际看到样本覆盖范围与总体不同。相机回宽是为了同时比较两者。 | 17.4秒范围停止形成主重音；17.5–20秒图解与概念稳定阅读。不要用强烈红叉把所有完成者经验都判错。 |

| 25–30秒 / 750–900 | 25.1–26.5秒拉回到完整总体构图并略回到开场的视线方向，尺度约1.12→1.0；26.5–27.0秒连线收束为结尾问题下划线，此后停止。 | 完成者仍在开场位置，但现在能看见完整报名队列、窗口边界和未知节点。几条已存在的调查连线收束到“谁没被看见？”下方，不把人物本体随意变成文字。 | 开场“只见局部”与结尾“知道局部之外仍有未知”形成因果呼应。收束不是删除总体；浅轮廓始终保留，提醒结论仍有未知。 | 26.5秒宽构图落定；27–30秒完整稳定阅读，不再推拉、不加漂浮。30秒整结束。 |

## 运镜与运动层次

- 主相机每次运动建议约0.9–1.3秒（27–39帧），开场小推可0.75秒。采用明确的加速—减速曲线，平移和缩放同步到达同一信息落点；不使用弹簧相机。
- 镜头运动期间最多一个主对象同时发生中等位移，其他对象保留位置。采访线的传播可以带路，但不能让全部节点同时闪烁、全部纸页同时飞走。
- 主动作先开始，辅助高光延迟约4–6帧跟进；主动作到达后给辅助状态0.15–0.25秒落稳，再进入阅读。避免相机、字、线、光同时抢第一拍。
- 深色背景只做小幅视差或局部柔光重心随焦点移动；不能造成图解漂浮。不要加无关星点、装饰坐标、镜头眩光或持续摇晃。
- 标签优先保留屏幕可读字号。需要靠近人物的图内标签可随相机变换，但最终显示不能小到读不清；必要时用固定标签层和短引线对应节点。
- 候选相机尺度上限约1.55，仅用于局部近景；低于1时必须检查标签，不为把世界全塞进画面持续缩小。若世界太宽，调整对象间距或分时标注，不缩小主字幕。

## 衔接必须由对象完成

1. 日历最后一天的方框→观察窗口的边框：同形同位置展开，观众知道观察窗口从何而来。
2. 报名队列→采访记录流：人的身份保留原地，记录纸页沿线移动；线是记录路线，不是时间轴或成功因果线。
3. 观察窗口范围→覆盖缺口：同一个矩形的范围变化，解释“样本不等于全部”，避免另换一张静态对比图。
4. 覆盖缺口→调查路径起点：前一步的问题成为后一步的动作原因。未知节点保持空心，表示问题还没查明。
5. 调查连线→结尾下划线：只收束连线和视觉重心，完整群体轮廓仍在；不要把所有数据变成一个没有上下文的口号。

## 动作效果音规划

本轮只提设计，不重新生成音轨。可复用现有工程的本地音效素材，由主 agent 检查音色、长度和实际音乐后调整。参考片音轨未人工试听，不能声称以下是复制其原音效。

| 建议落点 | 动作 | 声音功能 | 避免 |
|---|---|---|---|
| 0.85秒 | 第一份记录进入窗口 | 小而清楚的点击/纸片落定 | 每个字都敲击 |
| 4.0–5.25秒 | 拉远发现总体 | 单次短而柔的移动声，落点有轻质感 | 长啸声盖住音乐 |
| 10.3秒 | 采访记录进入窗口 | 一次清晰点击作为节奏重音 | 所有记录逐个同响 |
| 13.0秒 | 未被采访节点被看见 | 柔和提示或短低音，提醒注意缺失 | 失败警报/受伤声 |
| 17.4秒 | 覆盖框在缺口停止 | 克制的软停顿音 | 强烈错误蜂鸣 |
| 21.3秒 | 调查路径到达未知节点 | 轻连接声；字段可用一次次级点击 | 填完答案的胜利音 |
| 26.5秒 | 回到总体并落定 | 柔和收束音，尾部留白 | 到29秒仍新增重音 |

声音应对齐实际动作关键帧，而非强行每两秒一次。重要音效同期误差目标不超过2帧。配乐有检测起音不等于已经人工确认拍点，不能只靠自动节拍数据宣称卡准；最终以主 agent 的声画检查和可用试听为准。

## 核查与接受标准

- 关声音、遮住主标题，仍能由节点、视野、窗口与调查路径看懂：完成者被观察→总体中还有未被采访者→只看窗口不能代表全部→需补查未知。
- 4秒、9秒、15秒、20秒、25秒附近不是整画面统一淡出换图；至少有同一主体延续，前一动作产生下一动作。
- 新增运动不能盖掉原来用户认可的构图、字形和美观；主文案稳定，镜头停留真实可读。
- 不显示真实成功率或人物计数，不将停止打卡当停止跑步，不将空心节点视为失败；未知始终仍是未知。
- 运镜使信息焦点发生变化，每段都有“为何向这里看”的答案。删除任意一段镜头后若解释完全无变化，应考虑该镜头只是装饰。
- 除场景中段外，新增检查3.8/4.6/5.4、9.7/10.6/12.5/13.3、15.6/17.5、20.8/22.4、25.8/27.0秒的转场帧；重点观察文字裁切、相机落点、节点身份连续及未知状态。
- 保持900帧、30.000秒、1280×720、30fps。文字规划完成不代表动画代码、音轨或成片已完成。

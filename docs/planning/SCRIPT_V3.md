## A：30 秒聚焦版（900 帧）

定位：以打卡生活案例讲透“样本怎样被筛选”。谁/为何/原用途/基金与经营场所应用等转入配套知识稿；如要求四个核心点都在片中解释，采用 B 版并另行确认时长。

帧区间左闭右开。下列“屏幕文字”列出本页观众会读到的全部解释文字，图形不再偷偷增加假设数据。不显示示意人物的计数或比例。

### A1｜0–4 秒 / 0–120 帧：提出问题

- 解释目标：观众意识到“完成者评价”与“所有人的体验”不是同一个问题。
- 屏幕文字：图内「30天跑步打卡」「完成者分享」；底部两行「只问打卡到最后的人」「就能说计划容易？」；小注「教学假设」。
- 构图：中央一张线性日历，几个人物节点围绕最后一天，分享窗口只框住这些节点。底部问题句，暖珊瑚强调「就能」。
- 起点→动作→结果：日历上最后一天已亮→完成者的节点进入分享窗口，局部柔光照亮窗口→观众看见被问到的只是完成者，没有出现全体的结论。
- 可见结论：眼前只有一类人的意见。此时不展示“很容易”的真假答案。
- 转场：分享窗口保持位置，下一页镜头拉回扩大范围。
- 效果音建议：分享窗口落定一次轻点击；疑问出现一次柔和低音；不逐字敲击。
- 停留：1.5 秒前主问题完整出现，稳定至4秒。
- 风险：不能把成功分享画成真实采访；「教学假设」始终在场。

### A2｜4–9 秒 / 120–270 帧：找回总体

- 解释目标：判断该计划对报名者的坚持难度，需先知道最初有哪些报名者。
- 屏幕文字：图内「最初报名者」「完成打卡」「未完成：情况待问」；底部「最初报名的人，都在这里」；小注「教学假设」。
- 构图：镜头拉回形成一个总体边界，已观察青蓝节点与低亮空心节点共同位于边界内。两组节点不画成高低排名。
- 起点→动作→结果：只有分享窗口可见→镜头向外拉回，外围空心人物逐渐显出→完整报名队列与窗口同时可见。
- 可见结论：分享者只是最初报名者的一部分，空心人物的经历还未知。
- 转场：固定各人物位置；同一窗口在A3执行筛选。
- 效果音建议：镜头拉回一次短空气声；总体边界闭合一次木质轻敲。
- 停留：拉回用0.8秒，标签在5.3秒前落稳，剩余至少3.5秒阅读。
- 风险：节点多少不代表实际完成比例；不放百分比或人数。

### A3｜9–15 秒 / 270–450 帧：演示缺失是怎么发生的

- 解释目标：只采访完成者会系统性漏掉未完成者的打卡体验。
- 屏幕文字：筛选窗「只采访完成者」；窗外「未被采访」；底部两行「完成者的经历被听见」「未完成者的经历被漏掉」；小注「教学假设」。
- 构图：总体保留在中间，局部观察窗口位于右上；采访线从中央调查图标连到完成者，未被连到的空心人物仍看得见。
- 起点→动作→结果：所有报名者在场→采访线只连完成者，观察窗口内复制对应的完成者记录→窗口被强调，同时未入窗节点保留在原位置并出现「未被采访」。

### A4｜15–20 秒 / 450–600 帧：命名机制

- 解释目标：理解幸存者偏差指把筛选后留下的样本当成全体。
- 屏幕文字：图内「留下的样本」「最初的全部」；底部两行「幸存者偏差」「把留下的样本，当成全部」。
- 构图：左为总体，右为观察窗口，二者之间一个试图套用的范围框；不是两个不同人群的无依据对照。
- 起点→动作→结果：右窗样本向左总体投射一个覆盖框→框覆盖到空心人物时停住，出现短缺口→总体与样本各自标清，范围不再混同。
- 可见结论：样本的覆盖范围与总体不同，外推受限；不是声称所有缺失都带来同方向偏差。

- 停留：概念16秒前落稳，至少保持4秒。
- 风险：不使用强烈错误叉把所有成功经验整体否定。

### A5｜20–25 秒 / 600–750 帧：给出能执行的纠偏

- 解释目标：补查未知信息，而不是替未知者编造结果。
- 屏幕文字：图内「最初名单」「未完成原因？」；底部两行「补问未完成的人」「停止打卡 ≠ 停止跑步」；小注「教学假设」。
- 构图：名单图标连接总体，线性调查图标指向空心人物；未知节点旁保留问号。

- 可见结论：需要从最初总体追踪，未知不等于失败。
- 转场：调查线收拢到结尾问题，下页保留总体轮廓。
- 效果音建议：新增字段一次轻点击，关键不等式出现一次低音提示。
- 停留：21.2秒前文字全出现，至少保持3.8秒。
- 风险：不能把空心节点全部变亮，造成已完成调查的假象。

### A6｜25–30 秒 / 750–900 帧：带走一个问题

- 解释目标：遇到成功经验，先检查样本覆盖范围。
- 屏幕文字：底部两行「看见成功经验，先问」「谁没有被看见？」；图内仅保留「最初报名者」。
- 构图：总体节点退为低亮背景，但仍完整；局部柔光聚焦问题，与未被采访空心节点形成细线呼应。
- 起点→动作→结果：总体调查图→连线指向仍未知者，再收束成问题下划线→问题与空心节点保持静止。
- 可见结论：成功经验可参考，但需追问哪些经历缺失。
- 转场：不加品牌页，不引入额外结论，结尾直接结束。
- 效果音建议：收束一次柔和落音；尾部渐弱须待配乐选段后确定。
- 停留：27–30秒完整稳定阅读。
- 风险：结尾不把所有空心人物替换成“失败者”。

### B10｜62–69 秒 / 1860–2070 帧：现代意义之一——基金样本

- 屏幕文字：图内「起始基金样本」「现存」「退出样本」；底部「只看现存基金」「会漏掉退出样本的表现」；小注「机制示意，无收益数据」。

- 屏幕文字：图内「最初有哪些人？」「谁没有出现？」「算进去，还成立吗？」；底部「成功经验可以参考」「先检查样本，再判断结论」。

## 剪辑、声音和后续审核规则

- 一页一个解释单位。强视觉来自范围变化、筛选、缺口与重新纳入观察；不是增加无关装饰。
- 人物、飞机、基金及经营场所分别建立稳定身份。转场不换掉一批对象后继续冒充同一总体；教学人群始终无真实人数/比例。
- 每页主文字稳定后再给阅读时间，不持续漂浮。发光与柔光不应降低字形清晰度；线性图标保持统一线宽与尺度。
- 箭头语义按页统一：日历横轴表示时间；采访连线表示被观察关系；研究流程箭头表示信息输入与决策支持，不能当成受损直接导致某决策的因果证据。未知结局始终标问号、未知或未记录，不由节点亮暗代替结果。
- 动作音对齐主动作，计划同期误差不超过2帧；一页通常1–2个可辨声音，复杂页最多3个，不能所有线条同时发声。此处尚未制作任何效果音。
- 未试听音乐前不承诺落点；待获制作批准后，再针对音乐选段确认节奏、必要的压低和尾部处理。默认继续不调用付费服务。
- 正式制作前须用户审核本稿：选择A版30秒，或批准B版90秒；确认每页文字和解释链。如希望四核心点全部留在30秒，需要重新审核删减取舍，不能靠超速播放实现。
- 用户通过本稿前，不生成动画代码、图形素材、旁白、配乐、效果音、视频或预览。

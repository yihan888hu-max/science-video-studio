# 股票行情视频

本仓库使用 `projects/stock-video/` 内的 Remotion 工程，先读取其 `docs/STOCK-VIDEO-PLAYBOOK.md`。在其他工作区先查找该文档与股票配置，保留现有版本。

1. **研究先行**：先完成该股票的 `research/summary.md`，再写事件文案或动画。摘要包含证券身份、数据截止日/复权口径、主升段选取、低点到顶部涨幅与两种天数、催化时间线、论坛解读、术语证据表、准入片/待核验项目及来源。已授权制作时，摘要完成后继续，不额外设置审批关卡。
2. **时间对齐**：消息记录事件日期、首次公开时间、来源和可用的首个交易日。官方政策是产业背景，公告是公司事实，淘股吧等复盘是市场解读；在文案中保留这层区别。核对证券代码，避免把同名航天系公司公告移用。
3. **数据驱动**：图表按真实 OHLC 画蜡烛，前复权图表与未复权涨停判断分开。连板、炸板、缩量等先计算/核验，按[术语证据要求](references/market-language.md)选择可用表述。
4. **导演规则**：采用[本用户的制作规范](references/production.md)。单根迅速完成伸展后再停住，下一根稍后开始；暂停不是把一根的伸展卡在中间。平稳阶段也适当放大，快速拉升/急跌给近镜头，文字固定在屏幕层。关键高点显示低点—高点的收益幅度、日期、交易日与自然日口径。
5. **复用而非复制股票名**：行情、标签、消息、波段与时序放入每只股票的配置，公用图形/音效/相机组件读取配置。新股票必须重新研究与计算，不能沿用前股的事件、复权差额或监管规则。
6. **验收**：检查 OHLC、涨停口径、消息先后和波段公式；检查快伸展→完整保持→下一根的时序、取景、溢出和声画落点。实际渲染并解码抽帧，测量音频峰值与响度，交付 MP4、摘要、源码与复现方式。抽帧和信号分析的范围如实说明。

更换股票时先读两份 reference；只调整视觉时读取 production，新增交易术语时读取 market-language。

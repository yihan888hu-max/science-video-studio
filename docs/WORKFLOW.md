# 可复用制作流程

1. 定义观众的问题和视频要支持的观点。
2. 知识稿组查原始或权威资料，区分事实、推断、假设案例与未确定事项，记录来源。
3. 整理谁做了相关研究、为何研究、最初用途及现代意义；不能为了故事把经典应用者写成术语发明者。
4. 用户审核知识稿后，agent3编写逐页演示/剪辑稿。
5. 每页列精确屏幕短句、对象/构图、初始→动作→结果、可见结论、阅读停留、转场和动作音效；静音仍可理解。
6. 先做一张静态风格样张，确认画布、文字大小、配色和图形语法；不将静态通过视为自动通过全部动画。
7. 用户授权指定范围后，使用HyperFrames实施。优先代码绘图；有具体图片需要再检索或按授权生图。
8. 动效首先解释关系：同一总体身份稳定、观察窗口变化、镜头跟信息走；动作落定后留阅读时间。
9. 检查运行、版面、对比度与镜头接缝，修复错误后渲染；探测成片参数、抽取解码画面、测量声音。
10. 交付MP4、源码、素材来源和检查报告。明确抽帧/测量与人工听看之间的区别。
11. 用户要求先看一段时，到约定时长停止续作；GitHub上传单独等审核。

当前默认画布1280×720、30fps，时长由用户决定。图形教学假设持续标注，未知结局不能被图形暗示为失败。

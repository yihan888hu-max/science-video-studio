# 幸存者偏差：成功故事里，谁没有被看见？

> 知识稿组：Agent 1 主笔与历史查证，Agent 2 共同研究、生活案例与审稿。前期审核稿；Agent 2 已完成事实、案例与逻辑复核，未发现必须修改项。等待用户审核，未进入视频制作。

我们常听见成功者分享经验：这样学习容易上岸，这样经营能把店开好。听得多了，便容易觉得，照着做就会得到相近的结果。但有一个问题常被跳过：采用同样方法、最后没有成功的人，去了哪里？

这就是理解“幸存者偏差”的入口。它是选择偏差的一种：我们只观察经过筛选、留在视野中的一部分对象，却把这部分对象当成最初的全部。“幸存”不只指活下来，也可以是店铺仍在营业、基金仍在发行，或者某个人的经验被公开展示。当留下来的机会与我们关心的结果有关时，结论就可能失真。[1]

这套认识究竟是谁提出的？最著名的历史案例与统计学家亚伯拉罕·沃德有关。1943年，他在哥伦比亚大学统计研究组撰写了一系列飞机脆弱性研究备忘录，1980年由美国海军分析中心重印。可以确认他是这一经典研究的重要人物，但现有核查资料不足以确认，他是“幸存者偏差”一词的首次提出者或命名者。[2]

沃德为什么研究它？二战中，军方需要提高飞机及机组的生存机会。装甲有重量，不可能把飞机每个部位都无限加厚，必须判断哪里值得投入有限的防护。然而，能够检查的主要是能够返航的飞机；没有回来的飞机，其损伤情况无法同样完整地进入记录。沃德面对的，正是如何用这些不完整的数据估计风险的问题。[3]

设想返航飞机的机翼上有许多弹孔，某些部位的弹孔却很少。直觉可能让人先盯住弹孔最多的地方，但记录已经经过“能否返航”的筛选：飞机在某处受损后仍能回来，我们才有机会看到那个弹孔；某些严重受损的飞机若未能返航，它们的伤痕也就没有进入眼前的样本。眼前的分布描述的是“回来以后看见了什么”，不能直接等同于“所有飞机经历了什么”。

因此，原研究的用途是估计飞机受损与存活之间的关系，为防护和战术提供依据。它依靠数学方法及相应假设，不能简化成“哪儿弹孔少，就一定加固哪儿”：还需要考虑不同部位被击中的机会和飞机结构等条件。常见红点飞机图在这里也只适合作教学示意，不能当作真实作战损伤记录。[2][3]

换成日常生活，同样的筛选更容易看懂。假设一个跑步群开展30天打卡活动。到了最后一天，仍坚持打卡的成员纷纷说：“这个计划不难，坚持就行。”如果我们只采访这些人，就可能觉得计划对所有报名者都很容易。但中途退出打卡的人没有出现在这次采访里，他们的体验和困难也没有被算进去。这里是解释机制的假设案例，不是跑步活动调查数据。

更稳妥的做法，是从最初的报名名单出发，记录谁完成打卡、谁中途退出，再询问退出原因。停止打卡也不必然意味着停止跑步，不能仅凭群里看不见一个人，就替他判定结果。补回缺失信息，是为了回答原来的问题，而不是把所有未出现的人都想象成失败者。

这在今天有什么意义？它提醒我们检查经验背后的样本。比如只统计如今仍存在的基金，可能漏掉已经退出样本的基金，从而影响对历史表现的判断。研究者早已分析过这类存续筛选如何制造业绩似乎可预测的表象。[4] 统计经营场所的存续，也可以从同一年开业的一批对象开始，逐年追踪原始群体还有多少留下来，而非只访问今天仍开门的店铺。美国劳工统计局的相关统计就采用这种队列追踪方式。[5]

成功经验可以帮助我们提出假设，但单凭成功者的共同做法，还不能证明某种方法有效。即使找到了失败样本，要判断因果，也还需要合适的比较，考虑起点、资源和环境等差异。

下次遇到一个动人的成功故事，可以先问三句话：最初有哪些人参与？哪些人没有出现在叙述里？如果把他们也算进去，结论还成立吗？

## 表述边界

1. 跑步打卡是教学假设，无真实成功率、健康或减肥效果主张。
2. 并非所有缺失都造成同等或同方向偏差；关键是筛选与所研究结果的关系。
3. 补齐样本不自动证明因果；未通过筛选者也不必然在所有方面失败。
4. “弹孔少”的简化教学不能代替真实飞机防护工程判断。

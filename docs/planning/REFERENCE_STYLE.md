## 风格观察
1. 底色以近黑和深海军蓝为主，局部有宽而柔的明暗变化；主图四周留出大片空白。
2. 细线图形和轮廓占主要位置，青蓝与暖珊瑚橙承担对照和强调；发光集中在节点、图表端点、脚印、手机边缘等信息对象上。
3. 主画面一般只解释一个关系：年龄轴、变化曲线、日历积累、两个控制系统、杂乱方块、循环线条。图解随论述逐步增长或重组。
4. 底部短句独立于中央图解；关键词局部改色，正文不铺满屏幕。标题较大，图上标注较小；部分微小英文和角标在720P不宜照搬。
5. 不依赖每镜换场景：已出现的对象可保留位置，逐步补充第二种情况，形成比较；变化由线条、条形高度、路径和节点数量承担。
6. 观察到手机搜索框放大、画面从单个对象转向总体、脚印路径、图表增长等表现。仅凭抽样不能确定每一段的速度曲线或真实剪辑切点。

## 我方原创适配原则
- 输出维持1280×720、30fps。借鉴构图、色光、图解推进和信息节奏，使用已审核知识稿与原创图形。
- 背景拟用#080E18；文字#EDF3F7；强调色青蓝#8BD9ED、暖珊瑚#E7A08E。颜色为我方拟定，不声称逐像素提取。
- 局部柔光只包围解释焦点，节点可发光，连接线与线性图标保持细而清楚。拟用2–3px描边，底部短句约30–34px，标题约44–54px，图上关键标注不少于24–28px；制作时实际检查。
- 30秒版保持一个生活案例连续展开；完整知识稿的历史与用途需要更长的独立脚本方案，不在未确认时改变片长。
- 不照搬原片微小角标、平台外壳、水印和原片内容；用户说水印不用管，本轮无需擦除或复刻水印。

## Agent3逐页脚本要求
每页必须写：解释目标、精确屏幕短句、构图/对象位置、初始状态→运动过程→结束状态、观众能由画面得出的结论、转场、效果音建议、阅读停留、时长和误解风险。
每个知识要点必须指向一个可见证据。关掉声音后，短句和图像仍应形成完整逻辑。不能只写“表现幸存者偏差”“高级转场”等抽象制作词。
历史人物可用姓名年份和来源文件节点交代；统计机制必须用同一总体的选择与遗漏演示；现实意义必须有对象与结果的具体变化。
效果音绑定动作，背景音乐使用用户的 We Never vibebgm.mp3；参考片实际声音尚未核实，不能宣称复制了原片音效。
